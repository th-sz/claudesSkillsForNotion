# Claude Skills for Notion

Three Claude skills, connected to Notion through MCP, that I use for my computer science studies at Aix-Marseille University.

| Skill | Purpose |
|---|---|
| `subinit` | Creates the page for a new course in Notion: home, overview, an empty table of contents and a "Course pages" section. |
| `subcm` | Turns a lecture (PDF slides) into written course notes with a fixed colour code: a red passage is a definition, an orange one is a pitfall. The table of contents is extended without deleting anything. |
| `subhelp` | Adds a help section at the bottom of the page for a tutorial (TD) or lab (TP) session, at a level from 0 to 5. The method is given as numbered steps. |

## Requirement

The Notion connector must be enabled in the conversation with Claude.
